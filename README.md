# Cadastro Facial com face-api.js

Projeto simples para cadastro e reconhecimento facial usando **face-api.js**.  
Permite capturar rostos através da webcam e salvar os dados para reconhecimento futuro.

---

## Funcionalidades

- Captura de rosto via webcam.
- Cadastro de usuário com nome associado ao rosto.
- Exibição em tempo real do vídeo da câmera.
- Interface simples, responsiva e elegante.
- Mensagens de status para o usuário.

---

## Tecnologias Utilizadas

- [face-api.js](https://github.com/justadudewhohacks/face-api.js) — biblioteca de reconhecimento facial.
- HTML5, CSS3 para layout e estilização.
- JavaScript para lógica de captura e manipulação da webcam.

---

## Como usar

1. Clone este repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` em um navegador moderno (recomendo Chrome ou Firefox).
3. Permita o acesso à webcam quando solicitado.
4. Digite seu nome no campo e clique em **Capturar Rosto** para cadastrar.
5. Veja o vídeo e as mensagens de status na tela.
